# منصة «معالم التربية»

منصة متكاملة لبرنامج تأهيل المشرفين التربويين الجدد (الدفعة الثانية — الفصل الدراسي الأول 1448هـ)، مبنية على خطة البرنامج بكامل تفاصيلها: بطاقة البرنامج، ومصفوفة الكفاءات الثماني، والجدول الزمني الأسبوعي، وخطة مدير المشروع، وخطة المشارك، ونظام التقويم، والملاحق والنماذج.

## ما الذي تقدمه المنصة

**للمشارك** (`/app`)
- لوحة يومية: مهمة اليوم بحسب الروتين الأسبوعي، ومحتوى الأسبوع الحالي، وما ينتظره من مهام واختبارات، ومؤشرات التقييم المستمر.
- بطاقة القراءة اليومية (ملحق 4)، والتقرير الأسبوعي (ملحق 1)، والاختبارات التكوينية، والمهام الأسبوعية.
- سجل المعايشة الميدانية مع اعتماد المشرف المرافق، والدور القيادي مع استمارة تقييم الأقران (ملحق 5).
- مشروع التخرج، وخطة التعلم الشخصية وخطة المحفوظ، وسجل الوقفات التدبرية، ودفتر التأمل، ومتتبع العادات.
- ملف الإنجاز مع الدرجة التقديرية ومستوى الإتمام.

**لمدير المشروع** (`/admin`)
- لوحة تعرض مهام اليوم من مصفوفة المتابعة الأسبوعية والبنود المعلّقة.
- إدارة المشاركين وسجل الأداء (ملحق 3)، وتسجيل الحضور، ومراجعة التقارير مع التغذية الراجعة.
- إنشاء المهام وتقييمها بسلم التقدير (ملحق 2)، وبناء الاختبارات ونشرها، واعتماد المعايشة.
- اعتماد موضوعات مشاريع التخرج وتحكيمها (30 درجة)، وكشف الدرجات ومستويات الإتمام.
- قوائم تحقق مراحل المشروع وسجل المخاطر، وإرسال الإشعارات، وجلسات التغذية الراجعة الفردية.

**للمشرف المرافق** (`/mentor`): متابعة ساعات معايشة مجموعته واعتماد سجلاتها.

**عام**: صفحات وثيقة البرنامج كاملة (`/program`)، ودليل تثبيت التطبيق (`/install`).

## تطبيق الويب والإشعارات

- تطبيق ويب تقدمي قابل للتثبيت على الآيفون والأندرويد وسطح المكتب (ملف التعريف وعامل الخدمة والأيقونات جاهزة).
- إشعارات داخل المنصة لكل حدث (تسليم، تقييم، اعتماد، تذكير)، وإشعارات دفع للأجهزة المشتركة عبر
  Web Push
  بعد ضبط المفاتيح.
- تذكيرات تلقائية بحسب الروتين الأسبوعي (السبت، الأحد، الثلاثاء، الخميس، الجمعة، والقراءة اليومية) من نقطة مجدولة.

## التشغيل

```bash
npm install
cp .env.example .env        # ثم عدّل القيم
npm run vapid               # يولّد مفاتيح الإشعارات — انسخها إلى .env
npm run setup               # إنشاء قاعدة البيانات وبذر البيانات الأساسية
npm run dev                 # أو: npm run build && npm start
```

- حساب مدير المشروع الابتدائي: `admin` وكلمة المرور `Admin@1448` (أو قيمة `SEED_ADMIN_PASSWORD`). غيّرها فور الدخول.
- لبيانات تجريبية (مشرف مرافق وثلاثة مشاركين بكلمة المرور `123456`): `SEED_DEMO=1 npm run db:seed`.
- التذكيرات المجدولة: اضبط مجدولاً خارجياً يستدعي يومياً في الصباح بتوقيت الرياض:
  `GET /api/cron/reminders?key=<CRON_SECRET>`
- محلياً تعمل المنصة على
  SQLite
  في `prisma/dev.db`، وعلى Cloudflare تتصل بقاعدة
  D1
  تلقائياً.

## النشر على Cloudflare (الاستضافة وقاعدة البيانات والتخزين)

المنصة مهيأة للعمل على
Cloudflare Workers
عبر
OpenNext،
مع قاعدة بيانات
D1
وتخزين المرفقات في
R2
والتذكيرات اليومية عبر
Cron Triggers.

```bash
npx wrangler login
npx wrangler d1 create maalem-db          # انسخ database_id إلى wrangler.jsonc
npx wrangler r2 bucket create maalem-files
npm run d1:migrate                        # تطبيق migrations/ على D1 البعيدة
npx wrangler secret put AUTH_SECRET
npx wrangler secret put CRON_SECRET
npx wrangler secret put NEXT_PUBLIC_VAPID_PUBLIC_KEY
npx wrangler secret put VAPID_PRIVATE_KEY
npm run cf:deploy                         # البناء والنشر
node scripts/d1-seed.mjs --remote --password='كلمة-مرور-قوية'   # حساب المدير والمهام والاختبارات
```

- عدّل `NEXT_PUBLIC_APP_URL` و`VAPID_SUBJECT` في `wrangler.jsonc` قبل النشر.
- المعاينة المحلية بالبيئة نفسها (D1 وR2 محليتان): `npm run d1:migrate:local` ثم `npm run d1:seed` ثم `npm run cf:preview`.
- عند تعديل `prisma/schema.prisma` أنشئ ملف ترحيل جديداً في `migrations/` بالأمر `npm run d1:migration:new > migrations/000N_name.sql` ثم طبّقه.
- التذكيرات تعمل تلقائياً كل يوم 04:00 بالتوقيت العالمي (07:00 بتوقيت الرياض) من `wrangler.jsonc`.
- المرفقات (الشواهد وملفات المشاريع وسجلات المعايشة) تُرفع إلى
  R2
  عبر `/api/upload` وتُقدَّم بصلاحيات عبر `/api/files/…`؛ محلياً تُحفظ في `.data/uploads`.
- إشعارات الدفع تعتمد على حزمة
  web-push
  تحت توافق
  nodejs_compat؛
  إن تعذّر إرسالها على العامل فالإشعارات داخل المنصة تبقى تعمل.

## البنية

- `src/lib/program.ts` — بيانات البرنامج الثابتة المستخرجة من الخطة.
- `src/lib/grades.ts` — احتساب التقييم المستمر (70) ومشروع التخرج (30) ومستويات الإتمام.
- `src/lib/notify.ts` — الإشعارات داخل المنصة وإشعارات الدفع.
- `src/lib/dates.ts` — الأسبوع الحالي والتواريخ الهجرية والميلادية بتوقيت الرياض.
- `src/app/app` المشارك · `src/app/admin` مدير المشروع · `src/app/mentor` المشرف المرافق · `src/app/program` الوثيقة.
- `public/sw.js` و`public/manifest.webmanifest` و`public/icons` — تطبيق الويب.
