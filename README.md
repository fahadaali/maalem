# منصة «معالم التربية»

منصة متكاملة لبرنامج تأهيل المشرفين التربويين الجدد (الدفعة الثانية — الفصل الدراسي الأول 1448هـ)، مبنية على خطة البرنامج بكامل تفاصيلها: بطاقة البرنامج، ومصفوفة الكفاءات الثماني، والجدول الزمني الأسبوعي، وخطة مدير المشروع، وخطة المشارك، ونظام التقويم، والملاحق والنماذج.

## ما الذي تقدمه المنصة

**للمشارك** (`/app`)
- لوحة يومية: مهمة اليوم بحسب الروتين الأسبوعي، ومحتوى الأسبوع الحالي، وما ينتظره من مهام واختبارات، ومؤشرات التقييم المستمر.
- بطاقة القراءة اليومية (ملحق 4)، والتقرير الأسبوعي (ملحق 1)، والاختبارات التكوينية، والمهام الأسبوعية.
- سجل المعايشة الميدانية مع اعتماد المشرف المرافق، والدور القيادي مع استمارة تقييم الأقران (ملحق 5).
- مشروع التخرج، وخطة التعلم الشخصية وخطة المحفوظ، وسجل الوقفات التدبرية، ودفتر التأمل، ومتتبع العادات.
- ملف الإنجاز مع الدرجة التقديرية ومستوى الإتمام.

**لمدير المشروع** (`/admin`)
- لوحة تعرض مهام اليوم من مصفوفة المتابعة الأسبوعية والبنود المعلّقة.
- إدارة المشاركين وسجل الأداء (ملحق 3)، وتسجيل الحضور، ومراجعة التقارير مع التغذية الراجعة.
- إنشاء المهام وتقييمها بسلم التقدير (ملحق 2)، وبناء الاختبارات ونشرها، واعتماد المعايشة.
- اعتماد موضوعات مشاريع التخرج وتحكيمها (30 درجة)، وكشف الدرجات ومستويات الإتمام.
- قوائم تحقق مراحل المشروع وسجل المخاطر، وإرسال الإشعارات، وجلسات التغذية الراجعة الفردية.

**للمشرف المرافق** (`/mentor`): متابعة ساعات معايشة مجموعته واعتماد سجلاتها.

**دورة البرنامج كاملة**: ميثاق مشاركة يُوقَّع، وتقييم تشخيصي قبلي وبعدي يقيس أثر البرنامج، ومكتبة مواد للكتب والقوالب، وجدول قابل للتعديل بمواعيده وروابط حلقاته، ومحاضر اللقاءات، وإدارة الخبراء والضيوف وبدائلهم، والميزانية الفعلية مقابل المقدّرة، وبطاقة الكفاءات الثماني، وتقارير الجهة الشهرية والختامية، ووثائق الإتمام، واستبانة رضا مجهولة المصدر، وأرشفة ملف الإنجاز وتصدير الجداول.

**الدفعات**: لكل دفعة مشاركوها وجدولها ومهامها واختباراتها وميزانيتها وتقاريرها، ولا تختلط ببعضها. تعمل المنصة على الدفعة النشطة، وتُنشأ الدفعة الجديدة بجدولها وميزانيتها من الخطة. المكتبة وحدها مشتركة بين الدفعات.

**عام**: صفحات وثيقة البرنامج كاملة (`/program`)، ودليل تثبيت التطبيق (`/install`).

**معاينة تجربة المشارك**: يفتحها مدير المشروع من إعداداته، فيتصفّح واجهة المشارك بحسابه هو وللقراءة فقط — تظهر له المهام والاختبارات ومحتوى أسبوع البرنامج، ولا تظهر سجلات أي مشارك آخر، ولا يُحفظ أي تغيير، ويخرج منها بزر ثابت أعلى الشاشة.

**الدخول والصلاحيات**: واجهة دخول واحدة لجميع الأدوار. بعد الدخول — وعند فتح التطبيق المثبّت — يُنقل كل حساب إلى لوحته تلقائياً: مدير المشروع إلى `/admin`، والمشارك إلى `/app`، والمشرف المرافق إلى `/mentor`. ولكل دور منطقته وحده: أي محاولة للخروج منها تُعاد إلى لوحة صاحبها، والتحقق من التوقيع والدور يجري في كل صفحة وكل إجراء لا في طبقة التوجيه وحدها.

## تطبيق الويب والإشعارات

- تطبيق ويب تقدمي قابل للتثبيت على الآيفون والأندرويد وسطح المكتب (ملف التعريف وعامل الخدمة والأيقونات جاهزة).
- إشعارات داخل المنصة لكل حدث (تسليم، تقييم، اعتماد، تذكير)، وإشعارات دفع للأجهزة المشتركة عبر
  Web Push
  بعد ضبط المفاتيح.
- تذكيرات تلقائية بحسب الروتين الأسبوعي (السبت، الأحد، الثلاثاء، الخميس، الجمعة، والقراءة اليومية) من نقطة مجدولة.

## التشغيل

```bash
npm install
cp .env.example .env
npm run setup               # إنشاء قاعدة البيانات وبذر البيانات الأساسية
npm run dev                 # أو: npm run build && npm start
```

- عند أول تشغيل افتح `/setup` لإنشاء حساب مدير المشروع، أو استخدم `npm run setup` لبذر حساب `admin` بكلمة المرور `Admin@1448` (أو قيمة `SEED_ADMIN_PASSWORD`). البذر يقرأ `.env` بنفسه، وينشئ الدفعة الأولى وينسب إليها المهام والاختبارات والحسابات التجريبية.
- قاعدة أُنشئت بـ `prisma db push` تُعلَّم ترحيلاتها كمطبَّقة عند أول طلب تلقائياً، فلا تتعارض مع ملفات `migrations/`.
- لبيانات تجريبية (مشرف مرافق وثلاثة مشاركين بكلمة المرور `123456`): `SEED_DEMO=1 npm run db:seed`.
- الأسرار تُولَّد تلقائياً محلياً أيضاً؛ لا حاجة لضبط شيء في `.env` عدا مسار قاعدة البيانات.
- التذكيرات المجدولة تعمل تلقائياً على Cloudflare؛ ومحلياً يمكن استدعاؤها يدوياً من رابط يظهر في إعدادات مدير المشروع.
- محلياً تعمل المنصة على
  SQLite
  في `prisma/dev.db`، وعلى Cloudflare تتصل بقاعدة
  D1
  تلقائياً.

## النشر على Cloudflare (الاستضافة وقاعدة البيانات والتخزين)

المنصة تعمل على
Cloudflare Workers
عبر
OpenNext،
مع قاعدة بيانات
D1
وتخزين المرفقات في
R2
والتذكيرات اليومية عبر
Cron Triggers.
إشعارات الدفع تُرسل بتنفيذ يعتمد على
WebCrypto
فيعمل على العامل مباشرة.

### 1) النشر من المستودع (Workers Builds)

| الحقل | القيمة |
|---|---|
| Build command | `npm run cf:build` |
| Deploy command | `npx wrangler d1 migrations apply maalem-db --remote && npx opennextjs-cloudflare deploy` |
| Version command | `npx opennextjs-cloudflare upload` |
| Root directory | `/` |
| فرع الإنتاج | `main` |
| إصدار Node | 22 (محدد في `.node-version`) |

تنبيه: `npm run build` وحده لا يكفي — فهو يبني تطبيق
Next
فقط دون حزمة العامل، فيفشل النشر. وكذلك `npx wrangler deploy` وحده لا يبني الحزمة.

والترحيل في أمر النشر لا في أمر الإصدار: رفعُ فرعٍ غير إنتاجي يجب ألّا يمسّ قاعدة
الإنتاج، فيبقى Version command كما هو. و`&&` مقصودة: فشلُ الترحيل يوقف النشر ببناءٍ
أحمر مقروء، وهو خيرٌ من نشرٍ أخضر ثم انقطاعٍ متقطّع في الموقع.

الشرط الوحيد: أن يطابق حقل `name` في `wrangler.jsonc` اسم العامل المرتبط بالمستودع، وإلا أنشأ النشر عاملاً آخر.
كل دفعة إلى الفرع المرتبط تبني وتنشر تلقائياً. النشر اليدوي: `npm run cf:deploy`.
وفرع الإنتاج يُضبط في لوحة Cloudflare لا في المستودع، فتبديل الفرع الافتراضي في
GitHub وحده لا ينقل النشر إليه.

### 2) الأسرار — تلقائية

لا يوجد سرّ واحد تضبطه. مفتاح توقيع الجلسات، ومفتاح نقطة التذكيرات، ومفتاحا إشعارات الدفع
تُولَّد عشوائياً عند الإعداد الأولي وتُحفظ في قاعدة البيانات، وتبقى ثابتة بعدها.
ويمكن تجاوز أيٍّ منها بمتغير بيئة بالاسم نفسه إن رغبت.

### 3) قاعدة D1 وحاوية R2 — تلقائية

لا حاجة لإنشائهما يدوياً. الرابطان في `wrangler.jsonc` مذكوران بالاسم فقط دون معرّف، فينشئهما
wrangler
عند أول نشر (`maalem-db` و`maalem-files`)، ويعيد الربط بهما في كل نشر لاحق دون تكرار.
إضافة `database_id` يدوياً يعطّل هذا السلوك.

### 4) الإعداد الأولي من المتصفح

بعد أول نشر افتح `/setup`: ينشئ الجداول في
D1
مباشرة، وحساب مدير المشروع، والمهام والاختبارات الأساسية. يعمل مرة واحدة فقط ثم يُغلق.
بديل سطر الأوامر: `npm run d1:migrate` ثم `node scripts/d1-seed.mjs --remote --password='…'`.

### ملاحظات

- المعاينة المحلية بالبيئة نفسها (D1 وR2 محليتان): `npm run cf:preview` ثم افتح `/setup` — لا إعدادات مطلوبة.
- عند تعديل `prisma/schema.prisma` أنشئ ملف ترحيل جديداً في `migrations/` ثم `npm run sync:schema`؛ يطبّقه أمرُ النشر على القاعدة العاملة قبل رفع الحزمة. وما فات أمرَ النشر يُطبَّق عند أول طلبٍ بعده احتياطاً، ما لم يتجاوز اثنتي عشرة عبارة أو يعِد بناء جدول — فعندها يُسجَّل `boot.refuse` وتُخدَم الصفحة منقوصةً، والعلاج `npm run d1:migrate`. وسببُ الحدّ أن العامل يسقط عند خمسين طلباً فرعياً وD1 بلا معاملات، فترحيلٌ يموت في منتصفه يترك قاعدةً مسمومة.
- حالةُ الإقلاع تُقرأ من `GET /api/health` بلا استعلام واحد؛ وبمفتاح الكرون (`?key=…`) تُضاف مقارنةُ الترحيلات المطبَّقة بالمتوقَّعة.
- التذكيرات الثابتة تعمل تلقائياً كل يوم 04:00 بالتوقيت العالمي (07:00 بتوقيت الرياض)، والتذكيرات المخصصة تُرسل من الجدول الساعي، كلاهما من `wrangler.jsonc`.
- `public/_headers` يضبط رؤوس التخزين على Cloudflare: رقع `_next/static` ثابتة سنة، و`sw.js` يُراجَع دائماً.
- المرفقات (الشواهد وملفات المشاريع وسجلات المعايشة) تُرفع إلى
  R2
  عبر `/api/upload` وتُقدَّم بصلاحيات عبر `/api/files/…`؛ محلياً تُحفظ في `.data/uploads`.

## البنية

- `src/lib/program.ts` — بيانات البرنامج الثابتة المستخرجة من الخطة.
- `src/lib/grades.ts` — احتساب التقييم المستمر (70) ومشروع التخرج (30) ومستويات الإتمام.
- `src/lib/notify.ts` — الإشعارات داخل المنصة وإشعارات الدفع.
- `src/lib/secrets.ts` — توليد أسرار المنصة تلقائياً وحفظها في قاعدة البيانات.
- `src/lib/cohort.ts` — الدفعة النشطة وتصفية البيانات بها.
- `src/lib/weeks.ts` — جدول البرنامج القابل للتعديل.
- `src/lib/competencies.ts` — احتساب تحقّق الكفاءات الثماني من الشواهد.
- `src/lib/snapshot.ts` — أرقام المنصة لتقارير الجهة.
- `src/lib/webpush.ts` — تنفيذ إشعارات الدفع على WebCrypto.
- `src/lib/setup.ts` و`src/app/setup` — الإعداد الأولي وإنشاء الجداول.
- `src/lib/dates.ts` — الأسبوع الحالي والتواريخ الهجرية والميلادية بتوقيت الرياض.
- `src/app/app` المشارك · `src/app/admin` مدير المشروع · `src/app/mentor` المشرف المرافق · `src/app/program` الوثيقة.
- `public/sw.js` و`public/manifest.webmanifest` و`public/icons` — تطبيق الويب.
